# 实施计划

- [x] 明确独立创作、中文逐幕叙述的项目定位。
- [x] 建立架构、内容、视觉和模板文档。
- [ ] 完成本地 Git 初始提交与私有远程仓库同步（以实际仓库状态为准）。

## 阶段 1：样章与事实核查

- [ ] 收集 6.1 奈芙尔相关任务原始资料，标出任务段或视频时间点。
- [ ] 写出能独立审阅的样章，确认叙述详略与口吻。
- [ ] 扩成完整一幕，补齐前因后果。
- [ ] 校对事实、引用、信息揭示顺序与来源记录。

完成标准：用户认可阅读方式；正文主要事实可追溯；没有为了扩写而新增未经证实的情节。

## 阶段 2：最小阅读器

- [ ] 建立 Vite + TypeScript 工程与 Markdown 构建流程。
- [ ] 实现版本／幕目录、长文页、稳定路由和前后篇。
- [ ] 实现主题、字号、行宽、手机目录与防剧透标题。
- [ ] 实现本地阅读记录、继续阅读与导入导出。
- [ ] 校验元数据，确保草稿不进入发布产物。

完成标准：桌面和手机可以从头读完完整一幕；刷新和直接链接正常；插入另一篇不会让阅读记录串页。

## 阶段 3：首个可发布版本

- [ ] 补齐相邻的一幕，验证跨幕阅读与前后篇行为。
- [ ] 验证构建、移动端排版、键盘操作与损坏阅读记录的恢复。
- [ ] 确定代码和原创文章的许可，审查第三方素材。
- [ ] 决定托管平台与访问范围，再配置部署。

完成标准：覆盖范围明确，资料可核查，实际发布权限符合用户选择。
