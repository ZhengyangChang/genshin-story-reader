# 视觉与交互方向

## 参考与独立实现

参考 https://hesperine.github.io/Genshin-Stories/ 的安静阅读体验：侧栏目录、居中正文、日夜模式、底部翻页。以独立布局、样式和代码实现，不复制其 CSS、JavaScript、图标或文章。

## 阅读画面

浅色使用暖白背景、深灰正文和少量低饱和强调色；深色使用低亮度背景与柔和文字。正文使用系统中文字体，避免首版依赖外部字体服务。

桌面目录约 240–280px，正文默认约 34–38 个汉字宽；正文约 18px、行高约 1.8，最终以手机与桌面实读调整。标题层级清楚，留白用于分开场景，不用大幅封面挤占正文。

设置提供日夜模式、字号和行宽；记住用户选择，首次遵循系统主题。视觉参数是起点，先用完整长文验证，再定稿。

## 操作规则

- 桌面左目录可收起；手机使用抽屉，支持关闭按钮、遮罩和 Escape，管理焦点。
- 底部上一幕／下一幕保留防剧透标签；边界处明确禁用。
- 键盘左右键切换文章时避开输入框、设置控件及文本选择。
- 第一版优先明确按钮；手机滑动翻篇可后续补充，避免与纵向阅读冲突。
- 资料在文末可展开，外链有清楚标识。
- 提供继续阅读和手动标记读完，访问记录与读完记录分开。

## 验收重点

320px 宽屏无横向溢出；正文和控件对比度符合 WCAG AA；键盘可用、焦点可见；控件触控面积充足；系统减少动态效果时关闭非必要动画。

视觉验收用真实长文、中文长标题、来源链接与空目录，不能只靠短占位文本判断排版。首版不要求插画；图片需要时补充替代文字、来源和权利记录。

## 手机优先与多篇幅

手机目录入口与叙述版本切换保持可触及，主操作至少 44px 高；正文单栏，卡片就地展开。使用共享场景定位切换简述／详述。后续身份答案不放在折叠标题内，不依赖 hover 弹窗。
